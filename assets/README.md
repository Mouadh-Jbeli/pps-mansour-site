## Conseils
- Compresser les images avec TinyPNG ou Squoosh avant de les placer
- Le logo `logo-pps.png` doit avoir un fond transparent pour bien s'afficher sur la navbar
- Dans le footer (fond sombre), le logo est automatiquement inversé en blanc via CSS
- Les images portfolio sont affichées en `background-image` — ratio 4:3 ou 3:2 recommandé
- `deco-placo-01.jpg` et `deco-placo-03.jpg` sont affichées en format large (portfolio-item--wide)
- `staff-02.jpg` est affichée en format portrait (portfolio-item--tall)
